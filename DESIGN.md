# Flow Control — Creative Direction

## Visual metaphor
A full-stack developer as the person who keeps the flow between interfaces, APIs, async processing and data moving correctly. The hero object is a precision-built system core. The visitor travels past it, through the request path, into project monoliths, and finally out into an open contact scene.

Cyan represents information flow; coral marks operational action; violet separates product/project material; lime and amber are used sparingly for tooling and the final CTA.

## Story
1. Identity: Saimanti Maji, full-stack software developer.
2. Flow: Angular/UI → API → Node/FastAPI → RabbitMQ → workers → Redis → SQL/Mongo.
3. Selected systems: warehouse, healthcare, logistics and retail projects.
4. Production experience at Sastasundar Ventures.
5. Technical toolkit.
6. Contact / education.

## Motion principles
The camera follows a curved rail rather than jumping between arbitrary coordinates. Pointer movement only adds a small damped offset. FOV tightens around the middle of the story. 3D motion is continuous while DOM content remains readable and independently accessible.
